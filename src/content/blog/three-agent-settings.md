People write long, clever instructions for their custom agents and skip the three settings that actually decide how they behave.

1. What it can touch. A reviewer that can edit files will "fix" things instead of reporting them. Take the edit tools away and it can only do its job.

2. Which model it runs on. Match the model to the work, not to how important the task feels.

3. How it reports back. "Tell me what you found" gets you an essay. "Return each problem with the file, the line and how to reproduce it" gets you something you can act on.

Instructions matter. These three matter more.
