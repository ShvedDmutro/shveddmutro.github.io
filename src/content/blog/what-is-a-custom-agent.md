Most people use one AI agent for everything. Writing code, reviewing it, testing it, writing the docs.

That's like asking one person to be your developer, tester and technical writer at the same time.

A custom agent is a specialist. In tools like Claude Code it's a small text file with:
- one job, described in a sentence
- its own instructions
- what it's allowed to touch
- which model it runs on

The main agent hands it a task. It does that one job in its own clean space and reports back.

Why it helps: a specialist with narrow instructions makes fewer surprising moves than a generalist with a huge prompt. And your main conversation stays focused, because the specialist's work happens somewhere else.
