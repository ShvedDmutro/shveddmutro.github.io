Five custom agents that are useful in almost any dev team.

None of them are clever. That's the point. Each one does one job well and stays in its lane.

**Code reviewer.** Reads the changes and finds real problems. Can touch: read only. Reports each problem with proof: the failing case or the exact steps.

**Test runner.** Runs the tests and tells you what failed. Can touch: run commands only. Reports pass or fail and the failing tests word for word. Never fixes anything.

**Docs researcher.** Answers questions from the docs and the code. Can touch: read and search. Reports the answer and the source it came from.

**Release notes writer.** Turns this week's changes into plain words. Can touch: read the change history. Reports short notes users understand, with no jargon.

**Codebase guide.** Explains any part of the code to a newcomer. Can touch: read only. Reports a plain explanation and where to start reading.
