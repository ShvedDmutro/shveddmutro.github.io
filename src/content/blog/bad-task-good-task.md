Same agent. Same model. Very different results.

The only difference is the task I wrote.

A good coding agent reads your rules file and explores your code. But it still only knows what's written down or what it can find. Your intentions aren't in the repo.

Write the goal, the limits and "done when". It takes a minute and saves an hour of review.
