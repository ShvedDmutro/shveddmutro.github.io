I wrote down how I work with AI coding agents.

It's 22 pages, in plain words. How to give an agent a task it can't misread. How to choose the model. How to stop fixing the same bug three times. Why "done" from an agent means nothing until you check. And a list of red flags that tell you to stop.

There's no course and no sign-up. [Read the playbook (PDF)](/ai-coding-playbook.pdf).

What's inside:

- **The one idea:** the main model is the lead, agents are hands with no memory
- **Where the rules live:** short always-on rules, detail that loads only when needed
- **Step 0, the brief:** understand the task before the first edit
- **The task contract:** the 13 lines every agent task should have
- **Never accept "done":** what to check in every result
- **Picking the model:** one question decides
- **Root cause, not loops,** and why a bug is a shape, not a line
- **AI review must prove it:** a finding is a failing test, not an argument
- **Red flags:** when to stop

If one developer on your team should read it, send it to them.
